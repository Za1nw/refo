# قواعد إدارة ونظام الترجمة ومنع النصوص الثابتة (i18n & Zero Hardcoded Text Rules)

> **المرجع الإلزامي لكتابة النصوص، تنظيم ملفات الترجمة، ومنع استخدام أي نصوص ثابتة في واجهات الفرونت إند.**

---

## 1. القاعدة الصارمة: منع النصوص الثابتة نهائيًا (Zero Hardcoded Text Policy)

- **يُمنع منعًا باتًا كتابة أي نص عربي أو إنجليزي ثابت داخل كود الفرونت إند** (JSX / TSX / Components / Hooks / Modals / Tables / Forms / Buttons / Placeholders / Toasts / Tooltips / Labels / Dialogs).
- **المصدر الوحيد للنصوص هو ملفات الترجمة**: كل نص في الواجهة يجب أن يُستدعى عبر `t(...)` أو `tMain(...)` أو دوال `i18n.ts`.
- **تجهيز ملفات الترجمة العربية تلقائيًا**: عند بناء أي ميزة أو شاشة جديدة، يجب على المطور/الوكيل إنشاء وتجهيز النصوص العربية داخل ملف الترجمة المقابل في الباك إند أولاً، لتمكين ترجمة النظام إلى أي لغة أخرى لاحقًا دون لمس كود الفرونت إند.

---

## 2. قواعد تقسيم وتنظيم ملفات الترجمة

### أ. قاعدة المسارات

- **ملفات ترجمة الموديول**: توضع داخل الموديول نفسه:
  `Modules/[moduleName]/lang/[lang]/[filename].php`
  (مثال: `Modules/Courier/lang/ar/couriers.php`).
- **ملفات الترجمة العامة أو المشتركة**: توضع في المجلد الرئيسي:
  `lang/[lang]/[filename].php`
  (مثال: `lang/ar/main.php`, `lang/ar/profile.php`, `lang/ar/appearance.php`).

### ب. قاعدة: ملف ترجمة منفصل لكل صفحة (1-to-1 Page-to-File)

- **ممنوع دمج ترجمات صفحتين أو أكثر في ملف واحد**.
- كل صفحة تملك ملف ترجمة خاص بها باسم المورد/الصفحة.
- الـ Controller يطلب ملف الترجمة الخاص بصفحته فقط عبر `protected array|string $inertiaTranslationGroups = ['[page]'];`.
- الفرونت إند يستدعي الـ Namespace المطابق لاسم الملف: `const { t } = useTranslation('[page]');`.

### ج. قاعدة: الترجمات العامة المشتركة في `main.php`

- النصوص المتكررة والعامة في كل الصفحات (أزرار الحفظ والإلغاء، التصفح، البحث، رسائل العمليات والتأكيد العامة، الحالات المشتركة نشط/غير نشط) توضع **حصرًا** في `lang/[lang]/main.php`.
- تُشارك تلقائيًا في كل الصفحات وتُستدعى بـ `const { t: tMain } = useTranslation('main');` أو دالة `tMain(...)`.

---

## 3. قواعد صياغة المتغيرات (Interpolation Syntax)

- **نصوص الفرونت إند (React / i18next)**: تُكتب المتغيرات بصيغة الأقواس المزدوجة `{{var}}` (مثال: `'creating' => 'جاري إنشاء {{resource}} "{{name}}"...'`).
- **نصوص الباك إند و Blade (`__()` / `trans()`)**: تُكتب المتغيرات بنقطتين رأسيين `:var` (مثال: `'welcome' => 'أهلاً :name'`).
- ❌ **يُمنع استخدام `:var` في نصوص الفرونت إند**.

---

## 4. قائمة فحص سريعة قبل اعتماد أي كود (Checklist)

- [ ] هل توجد أي نصوص عربية/إنجليزية مكتوبة كنص ثابت داخل ملفات `.tsx` أو `.ts`؟ ⬅️ **إذا نعم، انقلها فورًا لملف الترجمة**.
- [ ] هل تم إنشاء وتحديث ملف الترجمة العربي المقابل في `lang/ar/...` أو `Modules/.../lang/ar/...`؟
- [ ] هل اسم ملف الـ PHP يطابق الـ Namespace المستدعى في `useTranslation('...')`؟
- [ ] هل المتغيرات في نصوص الفرونت إند مكتوبة بصيغة `{{var}}`؟
